# بسته نصب مسیر انگلیسی (PWA)

این بسته یک وب‌اپ قابل نصب است. برای نصب روی گوشی، فایل‌ها باید روی یک آدرس HTTPS قرار بگیرند؛ باز کردن مستقیم index.html به‌تنهایی نصب PWA را فعال نمی‌کند.

## راه ساده با GitHub Pages
1. یک مخزن (repository) جدید و عمومی در GitHub بساز.
2. همه فایل‌های این پوشه را در ریشه مخزن بارگذاری کن.
3. از Settings > Pages، گزینه Deploy from a branch را انتخاب کن و branch اصلی و پوشه /(root) را ذخیره کن.
4. پس از فعال شدن سایت، آدرس HTTPS آن را با Chrome گوشی اندروید باز کن.
5. منوی سه‌نقطه Chrome > Add to Home screen یا Install app را بزن.

## نکته ذخیره اطلاعات
اطلاعات برنامه در حافظه مرورگر ذخیره می‌شود. از همان آدرس و همان مرورگر استفاده کن و داده‌های سایت را پاک نکن.
